# 🛡️ Resolutions_CTF_cybersecurity

Writeups and solutions for cybersecurity challenges (**retos**) I solve to learn and
document my progress. Most come from **[thePwnLab](https://thepwnlab.es/retos)**.

Each challenge lives in its own folder with a full writeup (`README.md` + an HTML
version with screenshots) and its **completion certificate** alongside the
documentation.

> ⚠️ **Educational use only.** These writeups document challenges solved in authorized
> lab / CTF environments. Flags are masked and final payloads trimmed on purpose — the
> goal is to show the *method and reasoning*, not to hand over the solution.
